---

In case a contract was verified by accident, the deployer of the contract can ask Sourcify to delete its verification data. Requests are reviewed and approved by Sourcify maintainers.

Sign this message with the deployer account (`personal_sign`). The deployer is the `deployment.deployer` field of the [contract lookup](/docs/api/#contract-lookup).

```text
Sourcify contract deletion request

I am the deployer of the contracts below. I ask Sourcify to delete their verification data, source code included.

Service: sourcify-contract-deletion
Version: 3
Issued at: 2026-01-31T12:00:00Z
Contracts (1):
1:0xae519fc2ba8e6ffe6473195c092bf1bae986ff90
```

Each contract is one line `chainId:address` in lower case, sorted by chain id, then by address. Send the request not later than 15 minutes after the `Issued at` time:

```bash
curl -sS -X POST 'https://sourcify.dev/server/delete' \
  -H 'Content-Type: application/json' \
  --data-raw '{"contracts":[{"chainId":1,"address":"0xae519fc2ba8e6ffe6473195c092bf1bae986ff90"}],"issuedAt":"2026-01-31T12:00:00Z","signature":"0x..."}'
```

The answer has a `requestId`. Read the state (`pending`, `done`, `rejected`, `expired`, or `failed`) with:

```bash
curl -sS 'https://sourcify.dev/server/delete/<requestId>'
```

If you cannot sign with the deployer account, write to [hello@sourcify.dev](mailto:hello@sourcify.dev).
